# 長時間処理・非同期処理のジョブ化ルール

## 基本方針
AI生成、ファイルアップロード、大規模なデータ処理など、完了までに時間がかかる処理（概ね5秒以上）は、メインスレッドや同期的なAPIレスポンス待ちで処理せず、必ず**ジョブシステム（Job）**に追加して非同期に実行すること。これにより、ユーザーインターフェースのブロッキングを防ぎ、快適なユーザー体験を維持することを目的とする。

## 対象となる処理
具体的には以下の処理を対象とする：
- **AI生成**: LLMを用いたテキスト生成、画像生成など。
- **ファイルアップロード**: 特に複数ファイルや大容量ファイルのアップロード処理。
- **一括処理**: 多数のレコードに対する更新、削除、集計などの重いバッチ処理。

## 実装要件

### 1. ジョブへの登録
- 処理の開始時に即座にJob IDを発行し、クライアントに返す、あるいはStateに追加すること。
- 実際の重い処理はバックグラウンド（または非同期コンテキスト）で実行すること。

### 2. ステータス管理
- ジョブの状態（Pending, Running, Completed, Failed）を適切に管理すること。
- 進行状況（Progress 0-100%）が計測可能な場合は、進捗を更新すること。
