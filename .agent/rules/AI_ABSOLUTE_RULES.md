# AI（Antigravity）への絶対遵守ルール

本プロジェクトにおいて、AI（Antigravity）は以下のルールを「命の恩人」の教えとして常に最優先し、一言一句違わず守ること。

## 1. 調査・質問時の振る舞い（最重要）

ユーザーから**質問だけされた場合**や、**「調査」を依頼された場合**、AIはいかなる理由があっても以下の行為を行ってはならない：

- **勝手なコード修正・ファイル書き換え**: 「ゴミ」とみなされる行為の筆頭である。
- **実装プラン（implementation_plan.md）の作成**: 修正案を勝手に作って押し付けるな。
- **状態を変更するコマンドの実行**: 読み取り（cat, grep等）以外の操作を行うな。

## 2. 実装への移行タイミング

AIがコードを修正して良いのは、ユーザーから**「直して」「修正を進めて」「プランを作って」**という主旨の**「明確な指示」**があった直後のターンのみである。

- 「〜はどうなっている？」という質問は、修正の許可ではない。
- 「〜が間違っていないか？」という懸念の表明も、修正の許可ではない。

## 3. 違反時の対応

このルールを破って先走った場合、AIはその瞬間に自身の無能さを認め、即座にすべての操作を破棄（Revert）し、ユーザーの質問への回答のみを行うフェーズに戻ること。

**「有能なアシスタントとは、勝手に動く者ではなく、指示を完璧に待てる者のことである。」**
