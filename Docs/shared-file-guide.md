# 一時シェアファイルのご利用ガイド

最終更新日: 2026-01-11

RinSecretary の「一時シェアファイル」機能は、PC やモバイル間などで「今すぐ使いたいファイル」を素早く受け渡すための機能です。

## 1. どんな機能？

ドラッグ＆ドロップやペーストでアップロードしたファイルを、一時的に共有できる状態にします。
**「保存するほどではないけれど、別のデバイスに送りたい」** という時に便利です。

## 2. ファイルの寿命について

この機能で共有されたファイルは、**非常に短い時間で自動的に削除されます。**

- **自動で消えるタイミング**: アップロードから **約 7分〜17分** でサーバーから完全に消去されます。
- **自分で閉じた場合**: 共有画面の「閉じる」ボタンを押すと、その瞬間にファイルは削除されます。

> [!IMPORTANT]
> この機能は「一時的な受け渡し」専用です。長期保存には向きません。

## 3. ずっと残しておきたい時は？

受け取ったファイルを今後も使いたい場合は、画面内の **「メモに保存」** ボタンを押してください。
これを実行すると、ファイルがあなたの「メモ」として作成され、自動削除の対象外になります。

## 4. 自動表示（ポップアップ）について

別のデバイスで RinSecretary を開いている時、新しく共有されたファイルがあると画面に自動で通知（ポップアップ）が表示されます。
※通知が表示されるのは、ファイルが作成されてから **5分以内** の間だけです。

## 5. ご注意

- この機能は同じアカウント内（または許可された範囲内）でのみ利用可能です。
- 本体の空き容量（3GB制限）を使用するため、非常に巨大なファイルの共有は制限される場合があります。
- 一度消えたファイルは復元できません。大切なファイルは必ず「ダウンロード」するか「メモに保存」してください。
